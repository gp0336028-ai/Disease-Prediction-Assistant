# 🩺 Disease Prediction Assistant

A machine learning based web application that predicts the risk of diabetes using patient health information.

The project uses **XGBoost** as the final prediction model and **Streamlit** to provide an interactive web interface.

## 📌 Project Overview

The Disease Prediction Assistant takes the following patient information as input:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

Based on these inputs, the trained machine learning model provides:

* Diabetes risk prediction
* Estimated diabetes probability
* Model information and test accuracy

> ⚠️ **Disclaimer:** This application is intended for educational purposes only. It is not a medical diagnosis tool and should not replace professional medical advice.

## 🤖 Machine Learning Models

Three machine learning algorithms were trained and evaluated:

1. Logistic Regression
2. Random Forest
3. XGBoost

### Model Performance

| Model               |   Accuracy |
| ------------------- | ---------: |
| Logistic Regression |     70.78% |
| Random Forest       |     74.68% |
| XGBoost             | **75.97%** |

Based on the test accuracy, **XGBoost** was selected as the final model.

## ⚙️ Data Preprocessing

The dataset is divided into training and testing data using an 80/20 split.

The following preprocessing steps are performed:

* Invalid zero values in selected medical measurements are treated as missing values.
* Missing values are filled using the median.
* Features are standardized using `StandardScaler`.
* The preprocessing pipeline is saved as `preprocessor.joblib`.

## 🚀 Installation

Create and activate a virtual environment:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Install the required dependencies:

```powershell
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application using:

```powershell
.\venv\Scripts\python.exe -m streamlit run app.py
```

The application will open in the browser.
